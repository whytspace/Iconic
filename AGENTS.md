# Agent Notes

Read `CONTRIBUTING.md` for setup, checks, changelog, and project rules. Notes here cover what an agent can't derive from the repo.

- Targets **WoW Forever** (game type `camelot`, Interface 16001) first and current retail (Midnight, 12.x) second. Training data is stale for both clients — don't trust it for API behavior.
- For uncertain live-client behavior, ask the user to run a short in-game `/dump` — one or two copy-pasteable lines — instead of guessing.
- Blizzard's own UI is the API reference: https://github.com/Ketho/wow-ui-source-forever for WoW Forever, https://github.com/Gethe/wow-ui-source (branch `live`) for retail, branches `classic_era`, `classic_anniversary` and `classic` for the Classic clients.
- After a release, give the user the CurseForge description to paste: the README without the logo, Install and License, with relative links made absolute GitHub URLs.
- `Iconic_Data/*.lua` is generated by `scripts/build_data.py`; never edit it by hand.
